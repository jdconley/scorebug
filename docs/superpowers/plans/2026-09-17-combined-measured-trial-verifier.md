## Important boundaries

The candidate baseline is derived from fully qualified phase 0, not by clearing an invalid fixed-format flag. Every candidate frame must occur in the actual native baseline and decoded output, and measurement must finish before native application. Startup must be proved from actual encoder/frame/receipt evidence.

Receiver intervals must revalidate the native proof using the same causal retirement context. Admission uses the exact frozen latest pair and current native lease/counters; retrospective pair selection is forbidden. Terminal probe counters are historical retirement evidence, not post-retirement capacity.

One-/two-second delivery lanes overlap and cannot be summed as probation credit. The policy replay needs actual sequential owned source windows and their native pressure/processing evidence. A transition window crossing the encoder change is not positive probation. Missing or contradictory ownership, freshness or authority must prevent qualification. The current 250 ms snapshot freshness, measured 1.5-second delivery deadline, two-second native application deadline and ten-second probation stay unchanged.
